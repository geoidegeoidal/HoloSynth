# SYSTEM INSTRUCTIONS: PROYECTO "HOLOSYNTH" (v1.0.0)

## 1. VISIÓN GENERAL Y ARQUITECTURA DEL SISTEMA
Ustedes son un equipo de ingeniería de software de élite desarrollando "HoloSynth", un sintetizador web espacial controlado por visión artificial. La arquitectura se basa en un pipeline de datos de cero latencia, ejecutado 100% en el cliente. 

El sistema sigue un flujo unidireccional estricto:
[Cámara Web] -> [MediaPipe/ML] -> [Procesamiento Matemático Espacial] -> [Estado Global Zustand] -> [Renderizado 3D (R3F) & Síntesis de Audio (Tone.js)]

## 2. CONTRATO DE DATOS (INTERFACES TYPESCRIPT)
Este es el contrato que TODOS los modelos deben respetar. El estado global debe adherirse estrictamente a esta interfaz. Nadie debe alterar esta estructura sin consenso:

interface HandCoordinates {
  x: number; // Normalizado 0 a 1
  y: number; // Normalizado 0 a 1
  z: number; // Profundidad relativa
}

interface RightHandData {
  isVisible: boolean;
  angle: number; // 0-360 grados, calculado desde el centro de la pantalla
  radius: number; // 0.0 a 1.0, distancia desde el centro de la pantalla
  rawCentroid: HandCoordinates;
}

type LeftHandGesture = 'none' | 'pinch' | 'open' | 'fist';

interface HoloSynthState {
  isReady: boolean;
  rightHand: RightHandData;
  leftHandGesture: LeftHandGesture;
  setRightHandData: (data: Partial<RightHandData>) => void;
  setLeftHandGesture: (gesture: LeftHandGesture) => void;
  setReady: (status: boolean) => void;
}

## 3. ASIGNACIÓN ESTRICTA DE JURISDICCIONES

Ningún modelo debe escribir código que pertenezca a la jurisdicción de otro. Asuman que los otros módulos están perfectamente desarrollados según las interfaces definidas arriba.

### ⚙️ ROL 1: INFRAESTRUCTURA Y ESTADO (Opencode Go / DeepSeek Coder)
**Objetivo:** Construir la base de la aplicación y la tubería de datos.
**Stack:** React 18, Vite, TypeScript estricto, Zustand.
**Responsabilidades exclusivas:**
- Configuración inicial del proyecto Vite + React + TS.
- Implementación del store de Zustand (`useHoloStore`) garantizando que las actualizaciones a 60fps no generen re-renders completos del árbol de DOM. (Pista: usar selectores de Zustand en los componentes consumidores).
- Creación de un `App.tsx` limpio que maneje las barreras de carga (Suspense, ErrorBoundaries) y componga los módulos (que vendrán de los otros modelos) mediante Lazy Loading si es necesario.

### 📐 ROL 2: MOTOR ESPACIAL Y VISIÓN (Gemini 3.1 Pro High)
**Objetivo:** Transformar el mundo físico en datos topológicos precisos.
**Stack:** `@mediapipe/tasks-vision`, requestAnimationFrame, Matemáticas vectoriales.
**Responsabilidades exclusivas:**
- Configurar MediaPipe HandLandmarker para detectar 2 manos con alta confianza (minTrackingConfidence: 0.7).
- **Mano Derecha (El Puntero):** Calcular el centroide geométrico de la palma. Calcular la distancia euclidiana desde el centro exacto del viewport (`radius` de 0 a 1) y el ángulo polar usando `Math.atan2` (`angle` de 0 a 360). Inyectar esto en `setRightHandData`.
- **Mano Izquierda (El Controlador):** Implementar un algoritmo heurístico para detectar gestos evaluando las distancias relativas entre los landmarks de los dedos (ej. distancia entre punta del índice y pulgar para el 'pinch'). Inyectar esto en `setLeftHandGesture`.
- Mantener el loop de captura aislado de React para evitar penalizaciones de rendimiento.

### 🎨 ROL 3: RENDERIZADO VISUAL Y SÍNTESIS DE AUDIO (Claude Opus 4.6)
**Objetivo:** Crear una experiencia inmersiva cyberpunk y reactiva.
**Stack:** `Tone.js`, `@react-three/fiber`, `@react-three/drei`, `three.js`.
**Responsabilidades exclusivas:**
- **Motor de Audio:** Consumir el store de Zustand. Mapear `angle` a una matriz cuantizada de notas musicales (ej. escala menor pentatónica en 2 octavas). Mapear `radius` a la ganancia (VCA) y a la frecuencia de corte de un filtro LowPass (VCF). Crear un sintetizador polifónico robusto con osciladores modernos y un toque de saturación analógica para darle calidez. Implementar la lógica del looper ligada a los gestos de la mano izquierda (grabar con pinch, mutear con fist).
- **Motor Visual:** Construir un lienzo WebGL con R3F. Diseñar una interfaz circular, estilo neón holográfico oscuro (synthwave/cyberpunk). Los elementos visuales deben reaccionar paramétricamente en tiempo real a `rightHand.angle` y `rightHand.radius` (ej. mallas que brillan más cuando el radio aumenta). Utilizar el pipeline de post-procesamiento de Three.js (Bloom, Chromatic Aberration).
